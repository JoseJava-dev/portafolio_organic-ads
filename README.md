# Digital Spark Agency

Crea una pagina web  para mi agencia de marketing digital, esta pagina debe tener una seccion Principal donde muestre de forma muy minimalista que y para que sirve organiads similar a la imagen principal que te adjunte. 
- Una seccion de servicios con los servicios que aparecen en la otra imagen que adjunte.
- Seccion de casos de exitos en esta debe poder mostrar imagenes y videos. y tener la opcion de que el admin pueda eliminar, editar y agregar casos de usos.
- Una seccion de contacto donde apareceran las redes sociales, formulario de contacto y numero de telefono.

toma como referencia el estilo diseño y estica de las imagenes que adjunte, esa es la tarjeta de presentacion real.
